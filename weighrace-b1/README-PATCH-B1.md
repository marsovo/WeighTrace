# 秤迹 WeighTrace · 蚂蚁阿福 B1 补丁说明

本包是在开源项目 **WeighTrace（秤迹）** 基础上的修改版。原项目只支持蚂蚁阿福
A1（沃莱平台），本补丁通过真机抓包逆向 B1 的蓝牙协议，使 **蚂蚁阿福 B1
（薄荷联名款，广播名 `AFU-BH-TZ-B1`）** 也能使用：上秤自动读取体重与阻抗、
本地计算体成分，并可将主成员的实时测量写入 Apple 健康。

- 上游项目：WeighTrace by Xuan-lprk（GPL-3.0），本补丁遵循同一许可证发布。
- 本补丁为个人修改与真机实测成果，与蚂蚁阿福官方无关；官方从未发布过本 App。
- **仅支持 B1，不支持 A1**（两者是不同的硬件/协议平台）。
- 协议细节见 `docs/PROTOCOL-B1.md`，抓包记录见 `CAPTURES.md`；
  安装与使用见单独提供的《WeighTrace-B1补丁版使用指南》。

## 工作原理（要点）

- B1 通过自定义服务 FC50 的 AF000003 特征推送 20 字节 `AF 45` 帧：
  测量帧（子类型 0x51）字节 [2..3] 为体重（小端，单位克）；
  状态帧（子类型 0x52）字节 [4..5] 为阻抗（小端，单位 Ω，光脚约 500 Ω，
  穿袜/无人为 0 Ω）。连接后无需握手，订阅即可收数据。
- 体成分在本地计算：Segal（1988）公式为主，阻抗超出 100–1500 Ω 时回退
  Deurenberg（1991）。与官方 App 同场对比体脂约低 4 个百分点，属公式口径
  差异，非数据噪声——本补丁有意保持 Segal 原始口径，不做校准偏移。
- 写入 Apple 健康需要签名描述文件带 HealthKit 授权，且仅限主成员、
  称重时 App 保持前台打开的实时测量；历史记录不回填。

## 版本记录

### 基础适配（v1.0–v1.1）
- 按广播名前缀 `AFU-BH` 识别 B1，服务发现加入 FC50；
- 新增 AF 帧解析：按子类型分发体重/阻抗，复用原有保存与体成分流程。

### v1.2（2026-10-26）
- 修复首测问题：阻抗状态帧与体重帧异步到达，旧逻辑 4 秒回退会把体脂存成
  0 Ω 兜底值。改为稳定帧后主动轮询 AF000003（+2/5/9/14 秒）、回退窗口
  放宽到 20 秒、下秤零帧立即结算。
- **真机验证通过**：光脚 63.80 kg、阻抗 503 Ω、Segal 体脂 13.1%，
  发现/连接/体重/阻抗/体成分/本地保存全链路打通。

### v1.3（2026-10-27）

### v1.4（2026-10-27）

### v1.5（2026-10-27）

## 自动构建 IPA（GitHub Actions）

工程自带 `.github/workflows/release-ipa.yml`：把工程推到自己的 GitHub
仓库后，每次推送 main 或在 Actions 页手动运行，都会在 macOS 构建机上以
真机目标、关闭签名构建，把未签名 IPA 作为工作流产物上传（保留 90 天）；
推送 `v*` 标签时还会把 IPA 挂到 Releases，提供长期下载链接。IPA 未经
签名，安装前照旧过 LiveContainer / SideStore / 证书签名一遍。

## 已知事项

- 穿袜或脚底绝缘时测不到阻抗（0 Ω），体脂会走兜底估算，属正常现象。
- 秤同时只能被一台设备连接；官方 App 与本 App 不要同时连。
- 免费 Xcode 签名约 7 天过期需重签；使用带 HealthKit 授权的描述文件
  签名则可正常写入健康（以实际描述文件为准）。
